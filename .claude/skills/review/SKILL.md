# Code Review

## 检查重点

按以下优先级检查：

1. 明显 Bug
2. 逻辑错误
3. 边界条件
4. 异常和错误处理
5. 数据一致性
6. 并发和状态问题
7. 性能问题
8. 可维护性

## 流程

1. 优先查看当前 Git diff。
2. 理解修改涉及的上下文。
3. 必要时追踪相关调用方和被调用方。
4. 不要无目的阅读整个项目。
5. 按严重程度输出问题。

## 输出

优先报告真正可能造成问题的内容。

对于每个问题说明：

- 问题位置
- 问题原因
- 可能造成的影响
- 建议方案

如果没有发现明显问题，直接说明。

## 限制

- 不因为个人代码风格偏好提出低价值建议。
- 不要求为了“更优雅”而重构。
- 不修改代码，除非用户明确要求。
