# Bug Fix

## 流程

1. 明确 Bug 的实际表现和预期行为。
2. 定位相关代码。
3. 追踪数据流和调用链。
4. 找出根本原因。
5. 先说明原因和修复方案。
6. 如果存在多个合理方案或需求不明确，询问用户。
7. 实施最小范围修改。
8. 检查修复是否可能影响其他功能。

## 原则

- 优先修复根因。
- 不通过隐藏错误或增加特殊判断掩盖问题。
- 不修改无关代码。
- 不顺手进行重构。
- 优先遵循项目已有的错误处理方式。

## Token

- 从错误位置和调用链开始调查。
- 不要无目的扫描整个项目。
- 优先使用搜索和符号引用定位问题。
